# 🚀 JavaScript Array Methods Challenge

**Desafio superado e concluído com sucesso!** 🎯

Este projeto foi construído para praticar, dominar e aplicar os quatro métodos essenciais de manipulação de arrays no JavaScript: `forEach`, `map`, `reduce` e `filter`. 

---

## 💡 O Desafio e Suas Funcionalidades

A aplicação simula o gerenciamento de um menu iterativo, onde cada botão executa uma manipulação específica nos dados usando a lógica adequada:

1. **`forEach` (Mapear tudo):** Percorre a lista de itens e exibe todas as opções disponíveis na tela de forma dinâmica.
2. **`map` (Mapear):** Aplica uma transformação de cálculo em cada item, aplicando **10% de desconto** em todos os produtos do menu.
3. **`reduce` (Somar tudo):** Acumula e soma os valores de todos os itens do menu, exibindo o preço total consolidado.
4. **`filter` (Filtrar):** Filtra a lista para exibir **apenas as opções veganas** do menu.

---

## 🏆 Aprendizados e Domínio das Ferramentas

Com a conclusão deste projeto, consolidei o entendimento sobre a utilidade e a diferença técnica de cada método de iteração em JavaScript:

* **`forEach`** para iteração e renderização no DOM sem alteração do array original.
* **`map`** para criação de novos arrays transformados mantendo a imutabilidade.
* **`reduce`** para redução de dados a um único valor acumulado.
* **`filter`** para seleção condicional de dados específicos.
